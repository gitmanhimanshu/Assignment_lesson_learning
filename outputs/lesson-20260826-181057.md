# How Neural Networks Learn

## What is a Neural Network?
A neural network is a type of computer program. It is designed to learn from examples.

Think of an everyday activity like learning to throw a ball into a bucket. You stand in a room with a small ball. You want to throw the ball into a bucket on the floor.

On your first try, you throw the ball too hard. The ball flies two meters past the bucket. You see your mistake. Your brain measures the error.

On your second try, you throw the ball with less force. The ball falls short of the bucket. You make another small adjustment.

After ten tries, you throw the ball directly into the bucket.

A neural network learns in the exact same way. It starts by making a random guess. It checks how wrong the guess was. Then, it adjusts its internal settings to make a better guess next time.

In this daily life example, your arm acts like the neural network. The bucket is the target answer. The distance from the bucket is the error. Changing your muscle force is like changing the internal settings of the network.

## Why Do Neural Networks Matter?
In the past, humans had to write every rule for a computer.

For example, suppose you wanted a computer to recognize simple sentences. A person had to write a separate rule for every single word.

This old method required a lot of time. It did not work well for complex tasks. Human language has too many rules. Images have too many details. Writing rules by hand for every situation was impossible.

Neural networks solved this big problem. A neural network does not need hand-written rules. Instead, it looks at thousands of examples. It finds the patterns by itself.

This ability makes modern technology possible. It allows computers to understand human speech. It allows computers to identify objects in photos. It helps software translate text from one language to another automatically.

## The Three Main Parts of a Neural Network
To understand how a network learns, you must know its three basic parts.

First, a network has inputs. Inputs are the pieces of information you feed into the network. An input can be a picture, a number, or a text message.

Second, a network has internal settings. These settings are called weights. Weights act like small volume knobs inside the program. They control how much importance the network gives to each piece of input.

Third, a network has outputs. The output is the final prediction created by the network.

## Step-by-Step Learning Example
Let us look at a simple example. Suppose we want to train a network to read customer messages. The network must decide if a message is urgent or normal.

### Step 1: Input
We give the network this exact input text:
"Help, my account is blocked!"

### Step 2: Guess
At the start, all the internal weights are set to random numbers. The network reads the input text using these random weights.

Because the weights are random, the network makes a bad guess. It produces this complete generated final answer:
"Normal"

### Step 3: Error
The guess is incorrect. The true label for this message is "Urgent".

The network compares its guess to the true label. It measures the difference between the guess and the truth. This difference is called the error.

### Step 4: Adjustment
The network uses the error to fix itself. It works backward from the output to the inputs.

It adjusts its internal weights by a small amount. It turns up the weight for words like "Help" and "blocked". It turns down the weight for unhelpful words.

### Step 5: Result
We feed the exact same input text into the network again:
"Help, my account is blocked!"

The network processes the text using its updated weights. It produces this complete generated final answer:
"Urgent"

The network gave the correct answer because it adjusted its weights based on the error.

## Learning from Many Examples
A neural network does not stop after one example. It repeats this process thousands or millions of times.

This repeating process is called training. During training, the network looks at many different messages.

For example, we might give the network another input text:
"What are your business hours?"

At first, the network might guess "Urgent". The true answer is "Normal". The network calculates the error. It adjusts its weights again.

After seeing millions of examples, the internal weights reach the correct values. The error becomes very small. At that point, the network can read new messages that it has never seen before. It will correctly identify whether each message is urgent or normal.

## Summary
Neural networks learn through a simple loop:
1. Receive an input.
2. Make a guess using internal weights.
3. Compare the guess with the correct answer to find the error.
4. Adjust the weights to reduce the error.

By repeating this loop, a neural network teaches itself to solve hard problems without human rules.
