# How Neural Networks Learn

Imagine you are learning to play cricket. The first time you swing a bat, you might miss the ball. Your brain notices the mistake. Your brain adjusts your hands and eyes for the next turn. You try again. This time, you hit the ball. You learned by making a mistake and correcting it. A neural network learns in the exact same way.

## What Is a Neural Network?

A neural network is a type of computer software. It is designed to process information like a human brain. 

The human brain has billions of connected cells called neurons. A neural network has artificial neurons. We also call these artificial neurons nodes. 

These nodes are arranged in layers. The first layer receives raw data as input. The middle layers process the information. The final layer gives us an answer as output. 

A neural network cannot think on its own. It relies on mathematical calculations to make decisions.

## Why Does Learning Matter?

In old computer software, programmers wrote every single rule manually. For example, a programmer might write a rule to detect unwanted email messages. The rule might say: "If a message has the word 'money', block it." 

This approach has a big problem. Spammers can change their words quickly. Human programmers cannot write rules fast enough to catch every change.

Neural networks solve this problem. We do not write the rules for a neural network. Instead, we show it many examples of good messages and bad messages. The network studies these examples. It discovers its own rules automatically. This ability to discover rules from examples is called learning.

## The Key Concept: Weights

To understand how a network learns, you must understand weights. A weight is a number assigned to a connection between two nodes. 

Weights control how much importance a node gives to an input. A high weight means an input is very important. A low weight means an input is less important.

When a neural network is brand new, all its weights are random numbers. Because the weights are random, a new network makes terrible guesses. Learning is simply the process of changing these weights from bad numbers to good numbers.

## Step 1: Forward Pass

First, we give data to the network. The network passes the data through its layers of nodes. 

The nodes multiply the data by the current weights. The final layer produces a guess. This movement of information from start to finish is called the forward pass.

## Step 2: Loss Calculation

Second, we compare the guess to the actual correct answer. The difference between the guess and the correct answer is called the loss. 

Loss is just another word for error. If the network makes a huge mistake, the loss value is high. If the guess is close to correct, the loss value is low.

## Step 3: Backpropagation

Third, the network needs to know which weights caused the mistake. It sends the error value backward through the network. 

It checks every node and every weight. It calculates how much each weight contributed to the mistake. This backward movement of error is called backpropagation.

## Step 4: Weight Update

Fourth, the network updates its weights. It changes each weight by a small amount. 

If a weight caused a bad guess, the network reduces its importance. If a weight helped make a good guess, the network increases its importance. Now the network is ready to process the next example with better weights.

## An Example of Learning

Let us look at a simple example step by step. We want to train a network to identify spam messages. 

We give the network an input text.

Input message:
"Win money today click here"

The correct label for this message is:
"Spam"

Here is what happens during the first attempt:

Input text received by network:
"Win money today click here"

Generated output from network on attempt 1:
"Not Spam"

Correct label:
"Spam"

Calculated loss:
High error

The network performs backpropagation. It notices that the weight for the word "Win" was too low. It notices that the weight for "click" was too low. It changes the weights for these words to higher numbers.

Now we test the network again on the exact same input message:

Input text received by network:
"Win money today click here"

Generated output from network on attempt 2:
"Spam"

Correct label:
"Spam"

Calculated loss:
Zero error

The network successfully changed its output by updating its internal weights.

## Repeating the Process

A network cannot learn everything from one example message. It needs to look at thousands of different input messages. 

It repeats the four steps over and over again. This cycle repeats thousands of times. Each repetition makes the weights a little bit better. 

Eventually, the error becomes very small across all examples. When this happens, we say the network is trained. The trained network can now classify new messages correctly.

## Summary

Neural networks do not rely on fixed rules written by humans. They learn by guessing, checking errors, and fixing mistakes. 

Weights determine how strong connections are between nodes. The network makes a guess during the forward pass. It measures its mistake by calculating the loss. It traces mistakes backward using backpropagation. It updates its weights to reduce future mistakes. 

Over time, repeated practice turns random guesses into accurate predictions.
